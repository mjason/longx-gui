# Longx GUI

已重新初始化为最小 NSH TypeScript 原生应用。

当前包含与系统窗口标题栏合并的浏览器式服务器页签、位于浏览器地址栏位置的项目切换栏和空白内容区。系统窗口按钮与页签处于同一行，不再单独显示标题行。

服务器创建时从统一的彩色线条图标组中随机分配图标，前六项轮廓不重复，在当前窗口内切换时保持不变。项目 1/2/3 也是样式占位，可本地切换，各服务器分别记住当前项目；没有读取真实项目。

服务器标签支持关闭。关闭非当前项不切换；关闭当前项优先选右侧，否则选左侧。关闭最后一项保留窗口和“＋”入口。标签分隔线避开选中项及悬停项，关闭按钮有独立悬停反馈。关闭仅移除当前窗口中的本地页签，不删除远端数据。

“＋”可输入名称和地址，新增当前窗口内的本地服务器页签。初始三个页签为样式占位；尚未接入网络连接、持久化或其他业务功能，也没有 WebView。
后续实现等待用户逐步指导，不沿用上一版架构。
