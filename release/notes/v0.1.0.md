# Longx GUI v0.1.0

首个 macOS Apple Silicon 测试版本。

- 原生多服务器、多项目工作区，项目主页、快速切换及项目/全局设置。
- 可停靠的文件树、会话与 Git 面板，原生代码编辑和差异查看。
- 切换项目和面板时保留标签、未保存内容、阅读位置与布局；这些状态仅保留在当前窗口内。
- 原生会话输入，模型与思考强度选择、图片附件、排队和立即插入。
- 运行状态指示、进行中自动展开、结束自动收起，以及原生思考与基础图片/表格 View。
- 带签名验证的 OTA 和整包更新；下载与重启均由用户确认。

## 安装与限制

下载 `macos-aarch64.tar.gz`，解压并将 `Longx GUI.app` 放入可写的应用目录。
需要运行中的 Longx 服务，默认连接 `http://127.0.0.1:7788`。

正式 macOS 整包通过 GitHub Actions 的 Developer ID Application 签名、公证与 stapling 检查后生成。发布页附带的 `MACOS_DISTRIBUTION.json` 记录对应 archive hash。开发者本地无证书构建仍为 ad-hoc 测试包，不能当作已公证发行版上传，也不要为安装而关闭系统安全保护。

升级前请保存编辑器内容并处理草稿/排队消息；它们不会跨应用重启自动恢复。当前仅提供 macOS Apple Silicon 整包，其他平台尚未验证。View 中图表、表单及操作按钮等能力尚未完整接入。

OTA 的 build 与安装包使用同一个递增计数。初始安装包与附带 OTA 均为 build 1，因此安装首版后不会提示同 build 的 OTA；后续发布必须递增 build。
